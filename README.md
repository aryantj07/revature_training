# Revature Readiness Program — Git & Version Control Training

This repository tracks my hands-on practice, exercises, and project submissions completed during the **Revature Readiness Program**. 

## 🎯 Purpose
The goal of this repository is to establish a strong foundation in version control, collaborative development, and core software engineering workflows using Git and GitHub.

## 🛠️ Key Concepts Practiced
* **Repository Setup & Configuration:** Initializing repositories, configuring remotes (`origin`), and managing user identities.
* **Branching Strategy:** Creating isolated feature/development branches (`dev`, `feature-*`) to keep production code safe.
* **Commit Management:** Staging files (`git add`), committing changes with descriptive messages, and tracking repository status.
* **Pull Requests & Code Review:** Opening Pull Requests on GitHub to compare and merge branches.
* **Conflict Resolution:** Identifying and resolving merge conflicts locally using Git terminal commands.
* **Synchronization:** Syncing local and remote branches (`git pull --rebase`, `git fetch`, `git push`).

## 📁 Repository Structure
* `demo.txt` — Practice file for commit and merge conflict handling.
* `intro.txt` — Branch tracking and feature modification practice.
* `about.txt` — Feature branch workflow practice.
